# Smart Campus OS

A MERN stack based platform for managing college campus services.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- React.js

## Current Features

- Basic Express server
- Campus data API

## How to Run

Install dependencies:

npm install

Start the server:

node server.js

Server:

http://localhost:3000

Campus API:

http://localhost:3000/campus
